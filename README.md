## 📈 Core Business Insights & Analytical Features

### 1. Cost Variance Control (Procurement Protection)
*   **The Problem:** Traditional event planning suffers from hidden budget blowouts due to manual calculations.
*   **The Solution:** Built a dynamic `SUMIF`-driven **Financial Control Center** that aggregates estimates against real contract payouts. 
*   **Business Value:** Features automated **Exception Reporting** using conditional formatting rules that immediately flag budget overruns in red, allowing stakeholders to reallocate capital instantly.

### 2. Variable Demand Cost Forecasting (Supply Chain Optimization)
*   **The Problem:** Over-ordering catering plates based on speculative guest counts results in massive financial waste.
*   **The Solution:** Developed a dynamic catering cost calculation model that updates total expenditures based on live, confirmed RSVPs rather than rigid initial estimates.

### 3. Aging Debt Tracking (Cash Flow Risk Management)
*   **The Problem:** Multiple vendor contracts with fragmented due dates create severe liquidity management issues.
*   **The Solution:** Deployed a live `FILTER` array matrix that isolates active outstanding liabilities and calculates a real-time countdown to financial deadlines.
*   **Business Value:** Risk-ranks debts into immediate action categories (Overdue, Due in 7 Days, Safe) to manage short-term working capital smoothly.
